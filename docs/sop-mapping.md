# 会话决策与 SOP 工具映射

日期：2026-10-04。原依据为已交付的 SWB-SOP-IMG-001 v1.0 四册：会话总结、图片到文档 SOP、系统开发建议、数据契约与验收模板；其来源摘要保存在私有验收记录。本文是可公开的实施对照，不复制家庭档案。

原目录清理的结论是先按专题保留正式日期版本和历史稿，再逐文件比对集合、大小、SHA 后处理重复副本。原图、正式版本与已填写复测不因工具化删除；总目录说明保留。历史清理已有单独授权和记录，本 skill 没有删除入口，也不会因生成新版本而再次清理旧目录。

两条产品主线仍为知识／题库／地图／索引，以及观察／真实逐次作答／五维评价／个人档案。Skill 组织工作，机械工具保存约束与状态，Workbench 继续拥有业务真值、权限和追加修订；不建立第二份可任意覆盖的正式题库。

计算回归基线为 23 图、61 大题、81 原条目、91 节点；几何为 33 图、73 大题、77 原条目。本轮工具计算出几何 80 个节点，属于离线身份结构，不代表已入库。两套方法同号不混合；W8-4、W8-10 跨页，W9-1 左右，J4-9 与 W5-10 小问保留。原五册分页为计算 8/12/5/2/2、几何 10/14/3/4/4，新版应以实际验收报告为准。

重要勘误回归：整数两因子裂项系数 1/(3d)，分数三因子裂项系数 1/(2d)，求和保留完整起止；原计算三因子乘积和系数 1/3 应为 1/4。几何须确认同底／同高、平行、共角／共点、相似平方比、直角和斜边；W8-5 平行条件不足保留待核对。原文字与订正依据均留存，不改原图。

原 SOP G01～G18 与当前证据分开：来源／结构／数学／用途／PDF／Word 结构／本地发布可在本项目验证；目标 Word 实开、空业务实例联合恢复、实体手机与家庭复测、真实 OCR／供应商及费用不能由合成测试证明。真实新家庭保留集尚未提供，本轮匿名新批次只验证工作流泛化和失败处理，不报告识别准确率或学习收益。

模型任务未接入；benchmark 仅比较已有真值／预测／用量文件，真实调用、取消／迟到／未知费用须在提供方任务中记录。内容合法、机械检查、数学正确、教育有效分别计量。以后需模型时，先确定供应商、发送范围和预算，再冻结开发集／整页保留集；不能把跨页同题分到两边。
