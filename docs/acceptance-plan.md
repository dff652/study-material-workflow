## 必测场景

| 类别 | 场景及预期 |
| --- | --- |
| 发现与路由 | 明确整理照片、已有草稿继续生成、只要指定册别能选择对应流程；普通数学追问／单文件编辑不误触整套发布 |
| 来源 | 原图不变；重复、损坏、超限、裁断、缺页、路径逃逸和输出重叠有明确结果；照片时间不冒充作答时间 |
| 索引 | 数字小问、左右图、跨页选项、理论页、主辅名称映射、未知映射；全页阅读缺口显示；引用能反查原图 |
| 数学 | d=1 与非单位 d、起点前乘积不为零、分母非零、首尾及系数；等高／同底、平行／直角缺失和面积平方比不误套 |
| 证据 | 课堂／提示／独立／未知分开；不清字迹和空白不记错误；原资料勘误不归学习者；每次尝试追加 |
| 五册 | 共用输入快照、明确用途；独立卷无方法名／答案／暗示图；家长答案独立复算；证据不足生成待测说明 |
| 排版 | 分数线、上下标、中文新增字符、图中字母、长表格、留白及分页；全部 PDF 页视觉核对，不仅首页 |
| Word | ZIP／XML、OMML、内嵌图和留白通过；目标办公客户端实际检查与未验分别记录，不能靠 PDF 推断 Word 分页 |
| 继续与失效 | 失败／中断可定位；重复运行不覆盖历史；修改来源／内容／资源／依赖后下游旧验收失效 |
| 可移植性 | 新私有工作目录可运行；运行前检查工具／字体；缺能力给明确缺口，不硬编码旧 artifact 路径或自动安装 |

## 主代理验收记录

每轮 worker 交付后：先看完整真实差异及文件所有权，再独立执行本轮相关测试；修正错误后重跑受影响检查。正式签收记录精确源码与输入版本、实际命令、输出 SHA、数学结果、各页审查、未知和未验项。

结构验证或自述只证明对应范围；不得把离线文档验收扩写为已安装、已接入数据库、已部署、真实模型准确或学习改善。程序化检查与内容／教育判断分开记录。
