# SOP Skill 实施方案

版本：离线 v1；日期：2026-10-04。实施与验证已完成，实际范围及未验项见[任务清单](tasks.md)和[验收记录](verification-20261004.md)。本文保留设计依据与责任划分，不把生产接入计划写成已经执行。

## 目标与完成口径

首版将“读取选定资料→来源清单→整页阅读与索引草稿→内容核对→五册快照→PDF／Word→验证报告”串成可以复用的离线 skill。已有可编辑输入也能从对应阶段继续，无需重复读图。用户选择部分册别时保留原因，不强造评价结论。

五册分别为知识地图与总结、逐题分类索引、证据评价或待测记录、独立复测题、家长答案与观察点。独立题卷与家长答案单独构造。文档完成度、完整题库完成度和独立掌握证据分别报告。

## 项目及代码关系

本项目承载可复用 skill、CLI 和对应测试；Study Workbench 继续拥有领域身份、审核和学习历史。本地离线流程不能依赖数据库或已部署 Web 必然存在。

已复用一份纯 print_backend 及公式 AST／OMML／字体逻辑，计算和几何共用，初始来源文件摘要见 print-component-provenance.json。历史 v3／v2 内容从显式 JSON 导入，不执行旧 Python；字体和输出目录由配置给定。新增 diagram 语义、字符覆盖和字体字节身份，解决固定资料路径及缓存字形串用问题。Workbench 使用显式纯转换器导出，不改当前应用来绕过契约。

实际代码位于 `skills/study-material-workflow/` 的 SKILL.md、references/、scripts/、assets/ 和 agents/；项目根 tests/ 保存匿名合成测试。`.agents/skills/study-material-workflow` 是项目发现链接，未改全局配置。家庭输入、成果和主代理检查记录在忽略的 data/ 内。

## 输入输出与共享契约

唯一的共享[契约文档](workflow-contract.md)已冻结以下对象：

| 对象 | 要求 |
| --- | --- |
| 运行请求 | 来源根目录、明确选定文件、专题／分类修订、输出根、所需册别、运行模式及允许动作；敏感访问由本机配置提供 |
| 来源清单 | 原字节 SHA-256、大小、格式、尺寸、书册和页序；缺页／不可读记录；不改原图 |
| 题目草稿 | 稳定身份、父子、原显示题号、有序 photo_refs、摘要和题干分开、坐标或缺口、主辅方法及原始 raw |
| 内容快照 | 五册用途、语义块、公式 AST、图示来源／哈希、样式版本、审核依据；待测和已确认信息明确区分 |
| 运行状态 | 各阶段输入摘要、产物及哈希、失败与未知、需人工核对项；重入检查依赖是否变化，旧结果失效后不继续冒充已验 |
| 验证报告 | 数量、来源、数学、用途、PDF／Word 分项状态；机器通过、人工通过、未验分别记录 |

SOP 建议的 JSON Schema 是设计输入，未直接替代数据库／打印契约。实际 workflow CLI 为 prepare、render、verify、status；继续运行通过核对已有状态后重放相应命令完成，没有虚构 resume 命令。独立渲染／验证／打包／接入 CLI 各自承担职责。成功 0、失败 2，stdout 为单个 JSON；检查命令不安装依赖、不上传、不删除，也不隐式触发下一阶段。

## Skill 的行为

- 描述准确限定“整理学习资料并生成成果”场景；普通数学追问、单个 Word 修改或文件清理不自动走整套流程。
- SKILL.md 保留任务入口、范围选择、阶段路径、完成依据和停止条件；计算／几何规则、数据格式、排版与验收按需加载。
- 模型或 agent 协助人工阅读、编写、分类和变式时，输出为可核对草稿；不假装可通过固定脚本自动识别所有题目。
- 计算参考覆盖辅助构造、公差 d、3d／2d、起止与首尾检查；几何参考覆盖面积比、平行／直角／相似条件、跨页与精确绘图。
- 原图保留，印刷与笔迹分开；作者、日期及提示未知保留。原资料勘误与学习者错误分开；评价五维与逐次尝试不覆盖历史。
- NAS、安装、数据库和额外模型 API 不成为普通离线工作的隐式依赖；缺少必需能力时给出可操作的缺口，不静默改目标。

## 顺序与并行

实际按上述依赖顺序完成：一个 Luna6 第一轮负责 SWF-02／03，主代理并行完成 SWF-04；主审后同一 worker 第二轮负责 render／verify。主代理负责图示、纯 backend、五册语义、run、接入、恢复、打包与最终审查。全部 worker 文件与测试均由主代理阅读并独立执行验收。

Worker 不拥有 SKILL.md、共享契约、总状态、集成入口和主验收。若依赖尚未完成，只能做不依赖未定接口的准备，不能一边改契约一边并行实现。

SWF-08～10 的纯导出、本地／SSH 发布实现、文件评测和包工具已交付；真实数据库、生产 SSH 和真实模型没有执行。离线 v1 与这些未验接入分开，路线图不自动授权外部动作。本轮提供项目入口和源码分发包；新会话自动路由及全局安装未验。
