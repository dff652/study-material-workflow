## 新CLI会话行为

Codex CLI 0.159.2在三个独立新会话中实际执行：

1. 普通数学配对推导直接回答，used_skill为null，无命令或文件读写。
2. 从匿名已编写草稿生成逐题双格式、分讲仅PDF、汇总双格式，实际读取Skill与逐题SOP，生成6份文档及10个交付文件，验证并打包。过程中检测到主代理的工具修订，保留首轮版本，按当前摘要重新生成并验证，没有沿用旧配方签收。

主代理核对实际事件和成果；继续会话前的255个既有文件字节未变，子会话成果范围139文件的集合不增不减。主代理同期在自己的匿名目录追加最终审核和包，另行记录，没有混算成子会话写入。会话关闭其他MCP和记忆，只使用公共代码、匿名材料及指定字体；这三个案例不证明desktop／IDE安装或Word客户端行为。
