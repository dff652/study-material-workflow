# 计算资料规则

默认 profile 是 calculation-profile.json，可按明确新专题提供其他版本。六组为基础变形与换元、公式与通项、分数裂项、整数裂项、比较与估算、方程与新定义；旧照片引用用斜杠，小题支持 N(k)、N(k)-m。

知识卡记录变量、条件、为何有效、步骤、典型题／变式、检查点、来源和勘误。不要只给公式。

- 整数 a(a+d)：构造 P=a(a+d)(a+2d)、Q=(a−d)a(a+d)，提取共同因子后 P−Q=3d·a(a+d)。相邻抵消保留起点前乘积和末端乘积；d≠0，d=2 系数1/6，不能沿用1/3。
- 三因子倒数：1/[a(a+d)]−1/[(a+d)(a+2d)] 的共同分母分子为 2d，需再除 2d；所有分母非零。不要将整数和分数裂项系数混用。
- 通项校验第一项、项数与最后项；因式约分说明非零条件；正数和结果小于首项等明显范围矛盾必须复查。
- 原讲义三连续因子乘积求和曾把1/4误印成1/3；订正记录原文、位置和依据，不归到孩子的错题。

新编复测全部独立核算。可用 exact_math.py 检查受限四则有理数，不能用它替代未支持的代数证明。课堂示例或作者未知的正确笔迹不升级为独立掌握。
